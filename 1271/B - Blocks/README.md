<div class="header"><div class="title">B. Blocks</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>There are $$$n$$$ blocks arranged in a row and numbered from left to right, starting from one. Each block is either black or white. </p><p>You may perform the following operation zero or more times: choose two <span class="tex-font-style-bf">adjacent</span> blocks and invert their colors (white block becomes black, and vice versa). </p><p>You want to find a sequence of operations, such that they make all the blocks having the same color. You <span class="tex-font-style-bf">don't have</span> to minimize the number of operations, but it should not exceed $$$3 \cdot n$$$. If it is impossible to find such a sequence of operations, you need to report it.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains one integer $$$n$$$ ($$$2 \le n \le 200$$$) — the number of blocks.</p><p>The second line contains one string $$$s$$$ consisting of $$$n$$$ characters, each character is either "<span class="tex-font-style-tt">W</span>" or "<span class="tex-font-style-tt">B</span>". If the $$$i$$$-th character is "<span class="tex-font-style-tt">W</span>", then the $$$i$$$-th block is white. If the $$$i$$$-th character is "<span class="tex-font-style-tt">B</span>", then the $$$i$$$-th block is black. </p></div><div class="output-specification"><div class="section-title">Output</div><p>If it is impossible to make all the blocks having the same color, print $$$-1$$$.</p><p>Otherwise, print an integer $$$k$$$ ($$$0 \le k \le 3 \cdot n$$$) — the number of operations. Then print $$$k$$$ integers $$$p_1, p_2, \dots, p_k$$$ $$$(1 \le p_j \le n - 1)$$$, where $$$p_j$$$ is the position of the left block in the pair of blocks that should be affected by the $$$j$$$-th operation.</p><p>If there are multiple answers, print any of them.</p></div><div class="sample-tests"><div class="section-title">Examples</div><div class="sample-test"><div class="input"><div class="title">Input<div title="Copy" data-clipboard-target="#id00278931498745709" id="id0022512639067014906" class="input-output-copier">Copy</div></div><pre id="id00278931498745709">8
