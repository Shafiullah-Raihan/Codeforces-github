<h3><a href="https://codeforces.com/contest/2065/problem/F" target="_blank" rel="noopener noreferrer">Skibidus and Slay</a></h3>

<div class="header"><div class="title">F. Skibidus and Slay</div><div class="time-limit"><div class="property-title">time limit per test</div>4 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>512 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p> </p><p>Let's define the <span class="tex-font-style-it">majority</span> of a sequence of $$$k$$$ elements as the unique value that appears strictly more than $$$\left \lfloor {\frac{k}{2}} \right \rfloor$$$ times. If such a value does not exist, then the sequence does <span class="tex-font-style-bf">not</span> have a majority. For example, the sequence $$$[1,3,2,3,3]$$$ has a majority $$$3$$$ because it appears $$$3  \gt  \left \lfloor {\frac{5}{2}} \right \rfloor = 2$$$ times, but $$$[1,2,3,4,5]$$$ and $$$[1,3,2,3,4]$$$ do not have a majority.</p><p>Skibidus found a tree$$$^{\text{∗}}$$$ of $$$n$$$ vertices and an array $$$a$$$ of length $$$n$$$. Vertex $$$i$$$ has the value $$$a_i$$$ written on it, where $$$a_i$$$ is an integer in the range $$$[1, n]$$$.</p><p>For each $$$i$$$ from $$$1$$$ to $$$n$$$, please determine if there exists a non-trivial simple path$$$^{\text{†}}$$$ such that $$$i$$$ is the <span class="tex-font-style-it">majority</span> of the <span class="tex-font-style-bf">sequence of integers written on the vertices</span> that form the path.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$A tree is a connected graph without cycles. </p><p>$$$^{\text{†}}$$$A sequence of vertices $$$v_1, v_2, ..., v_m$$$ ($$$m \geq 2$$$) forms a non-trivial simple path if $$$v_i$$$ and $$$v_{i+1}$$$ are connected by an edge for all $$$1 \leq i \leq m - 1$$$ and all $$$v_i$$$ are pairwise distinct. <span class="tex-font-style-bf">Note that the path must consist of at least $$$2$$$ vertices.</span></p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$). The description of the test cases follows. </p><p>The first line of each test case contains a single integer $$$n$$$ ($$$2 \le n \le 5 \cdot 10^5$$$)  — the number of vertices.</p><p>The second line of each test case contains $$$a_1,a_2,\ldots,a_n$$$ ($$$1 \le a_i \le n$$$)  — the integers written on the vertices.</p><p>Each of the next $$$n-1$$$ lines contains two integers $$$u_i$$$ and $$$v_i$$$, denoting the two vertices connected by an edge ($$$1 \le u_i,v_i \le n$$$, $$$u_i \neq v_i$$$).</p><p>It is guaranteed that the given edges form a tree.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$5 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, output a binary string $$$s$$$ of length $$$n$$$ on a separate line. $$$s_i$$$ should be computed as follows:</p><ul> <li> If there is a non-trivial path containing $$$i$$$ as the majority, $$$s_i$$$ is '<span class="tex-font-style-tt">1</span>'; </li><li> Otherwise, $$$s_i$$$ is '<span class="tex-font-style-tt">0</span>'. </li></ul></div><div class="sample-tests"><div
