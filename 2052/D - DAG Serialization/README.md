<h3><a href="https://codeforces.com/contest/2052/problem/D" target="_blank" rel="noopener noreferrer">DAG Serialization</a></h3>

<div class="header"><div class="title">D. DAG Serialization</div><div class="time-limit"><div class="property-title">time limit per test</div>3 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>1024 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>Consider a simple single-bit boolean register that supports two operations:</p><ul> <li> <span class="tex-font-style-bf">set</span> — sets the register to <span class="tex-font-style-bf">true</span> if it was <span class="tex-font-style-bf">false</span>, and returns <span class="tex-font-style-bf">true</span>; otherwise, it returns <span class="tex-font-style-bf">false</span>; </li><li> <span class="tex-font-style-bf">unset</span> — sets the register to <span class="tex-font-style-bf">false</span> if it was <span class="tex-font-style-bf">true</span>, and returns <span class="tex-font-style-bf">true</span>; otherwise, it returns <span class="tex-font-style-bf">false</span>. </li></ul><p>The initial state of the register is <span class="tex-font-style-bf">false</span>. Suppose there were $$$n$$$ operations $$$op_i$$$ (for $$$1 \le i \le n$$$) where <span class="tex-font-style-bf">at most two operations returned true</span>. Also, we are given the partial order of operations as a directed acyclic graph (DAG): an edge $$$i \rightarrow j$$$ means that $$$op_i$$$ happened before $$$op_j$$$. You are asked whether it is possible to put these operations in some linear sequential order that satisfies the given partial order and such that if operations are applied to the register in that order, their results are the same as given.</p></div><div class="input-specification"><div class="section-title">Input</div><p>In the first line, you are given an integer $$$n$$$ — the number of operations ($$$1 \le n \le 10^5$$$). In the following $$$n$$$ lines, you are given operations in the format "<span class="tex-font-style-it">type</span> <span class="tex-font-style-it">result</span>", where <span class="tex-font-style-it">type</span> is either "<span class="tex-font-style-tt">set</span>" or "<span class="tex-font-style-tt">unset</span>" and <span class="tex-font-style-it">result</span> is either "<span class="tex-font-style-tt">true</span>" or "<span class="tex-font-style-tt">false</span>". It is guaranteed that at most two operations have "<span class="tex-font-style-tt">true</span>" results. </p><p>In the next line, you are given an integer $$$m$$$ — the number of arcs of the DAG ($$$0 \le m \le 10^5$$$). In the following $$$m$$$ lines, you are given arcs — pairs of integers $$$a$$$ and $$$b$$$ ($$$1 \leq a, b \leq n$$$; $$$a \neq b$$$). Each arc indicates that operation $$$op_a$$$ happened before operation $$$op_b$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>Print any linear order of operations that satisfies the DAG constraints and ensures the results of the operations match the ones given in the input.
