Otherwise, Nivek wins. </li></ul><p>Kevin wants to know the minimum amount of time he needs to spend to ensure he wins at least $$$k$$$ matches.</p><p>Output the answers for $$$k = 0, 1, \ldots, n$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases.
